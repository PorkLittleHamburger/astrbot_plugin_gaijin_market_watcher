新增覆盖：

- 真实盘口买入按外部卖价成交、买单冻结与撤单返还、卖单 FIFO 成本和 15% 逐件取整。
- 部分成交、剩余订单继续挂单、同一盘口版本不重复成交、旧盘口不能覆盖新盘口。
- 盘口版本与已消费可见深度重启后恢复；卖空批次不会被重启或场景克隆复活。
- 场景只补当前缺口、自动在买卖目标间切换，且任何阶段都保证买一低于卖一。
- 场景期间当前规则的基础挂单休眠；场景消费在重启后继续生效；场景结束后同一幂等键仍返回原订单。
- 写盘失败时内存账户、冻结资金、订单和成交回滚，不留下无法持久化的幽灵状态。
- 自动规则部分买入后立即卖出、买卖并行阶段可调度、风险额度拦截、账户重置清理规则状态。
- 旧交易数据迁移只清理交易规则/运行态/静态盘口/日志，保留账户、订阅、模板、风险设置和全局模式。
