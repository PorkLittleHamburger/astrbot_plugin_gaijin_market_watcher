## QQ 实机测试

### 私聊

私聊窗口为“真珠”，所有命令均直接发送，不使用 @。

| 命令 | 结果 |
| --- | --- |
| `/sid` | 返回 FriendMessage、UMO 和测试 QQ UID |
| `/gjm trade list`（未授权） | 明确拒绝：“仅插件拥有者可以操作自动交易。” |
| `/gjm trade list`（临时授权后） | 返回当前模拟规则列表 |
| `/gjm help` | 返回完整指令清单 |
| `/gjm status` | 返回监控、令牌、推送状态 |
| `/gjm trade budget` | 返回总开关、总预算、日限额、单笔上限 |
| `/gjm sub <F-16XL>` | 返回“已更新订阅：F 16Xl Usa” |
| `/gjm mysub` | 返回当前会话订阅和全局监控物品 |
| `/gjm refresh interval 15` | 返回已设为 15 秒 |
| `/gjm refresh mode only_change` | 返回已设为 only_change |
| `/gjm unsub 1` | 返回“已取消订阅：F 16Xl Usa（剩余 0 件）” |
